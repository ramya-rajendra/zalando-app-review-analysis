# Tagging decisions

Themes added after reviewing parts 1–4: app_design_ux, product_content.

- Design, layout, navigation, pop-ups, ads and positive usability comments → app_design_ux
- Crashes, freezing, errors, settings that don't work → app_performance (bug, not design)
- Vague "unusable since update" → app_performance
- Mixed reviews → the problem the reviewer mentions first
- Product descriptions, material info, images, videos → product_content
- Loyalty program (Plus status, bonuses) → prices_promotions
- Account blocked because of returns → returns_refunds
- Account blocked with no reason → account_login
- Political or boycott comments → other, exclude = yes
- Ambiguous "sehr langsam" → app_performance

Result of the re-check: 97 of 189 app_performance reviews were really design complaints.
